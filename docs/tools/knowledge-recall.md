# `knowledge_recall`

현재 판단에 영향을 줄 수 있는 과거 지식을 목적과 깊이에 맞춰 조회합니다.

이 도구는 Git, Workflow Registry, 현재 diff, 현재 테스트 결과를 대신하지 않습니다. 반환된 기억은 현재 저장소 증거로 다시 확인해야 합니다.

목적별 form/domain 기본 filter가 적용됩니다. source facts와 raw chunks는 provenance 또는 원문 문맥이 실제로 필요할 때만 포함합니다.

자세한 정책과 예시는 [ZZ Knowledge](../knowledge.md)를 참고하세요.
