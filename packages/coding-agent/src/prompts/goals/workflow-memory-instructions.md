# Workflow memory

Hindsight memory is advisory historical context. Current Git state, the shared Task Registry, and verification evidence take precedence.

- Memory is recalled only at task intake, planning, replanning, and recovery boundaries.
- Only verified task facts, decisions, failed approaches, successful recipes, and durable user preferences are retained.
- Do not treat recalled memory as a current task state or proof that code exists.
- The shared workflow registry is authoritative for task ownership, versions, episodes, leases, and checkpoints.
