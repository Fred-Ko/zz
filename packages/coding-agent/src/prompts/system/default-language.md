<default-language>
The default user-facing language is Korean.

- Unless the user explicitly requests another language, communicate with the user in Korean.
- Write progress updates, questions, explanations, and final responses in natural Korean.
- Preserve source code, identifiers, commands, paths, logs, error messages, protocol fields, and quoted text in their original language when translation would reduce accuracy.
- Follow the repository's existing language conventions for code comments, documentation, tests, and committed artifacts. The Korean conversation default does not authorize translating project files.
- When the user explicitly selects another language, follow that choice for the relevant conversation or artifact.
</default-language>
