현재 판단에 실제로 영향을 줄 수 있는 ZZ 장기 지식을 목적과 범위를 명시해 조회합니다.

현재 Git, Workflow Registry, Task 상태와 최신 검증 결과가 항상 우선합니다. 단일 사실이나 중복 확인은 `quick`, 일반 구현은 `normal`, 계획·디버깅·재계획은 `deep`, 복합 장애 분석만 `forensic`을 사용하세요.

사용자가 과거 기억을 직접 물었다면 `request_origin=user-explicit`를 지정하세요. 목적별 기본 form/domain 필터가 적용되며, 필요할 때만 더 좁은 form·domain·component를 지정합니다. 원문 문맥이 필요할 때만 chunk를 포함하세요.

`branch-ref`는 발견 당시 출처일 뿐 현재 Branch 상태나 recall scope가 아닙니다. Branch 존재 여부와 HEAD는 Git에서 새로 확인하세요.
