도구의 원시 결과와 모델의 해석을 분리하기 위해 증거에 연결된 관찰, 가설, 모순 또는 위험을 Registry에 보고합니다. 검증되지 않은 해석을 사실이나 완료 증거로 보고하지 마세요.

현재 단계의 가정·사전조건·예상 효과와 실제 상태가 충돌하면 즉시 contradiction 또는 workspace-change로 보고하고 관련 step/assumption/artifact ID를 `affects`에 연결하세요. Runtime은 이를 RECONCILING으로 전환해 추가 부작용을 막습니다. 단순한 새 정보가 계획의 범위를 구체화할 뿐 기존 계약을 반증하지 않으면 fact로 보고한 뒤 expansion patch를 제안할 수 있습니다.
